# NCM 转换器

一个基于 Wails 框架构建的网易云音乐 NCM 格式转换器 GUI 应用。

## 功能特性

- ✅ **多种方式添加文件：
  - 选择单个或多个 .ncm 文件
  - 选择目录（自动搜索其中的 .ncm 文件
  - 添加程序所在目录
  - 支持拖放文件和目录到窗口

- ✅ **完整的文件管理：
  - 表格显示文件列表（ID、路径、曲名、格式、大小、封面状态、转码状态）
  - 右键菜单（查看日志、打开文件位置）
  - 清空列表功能

- ✅ **状态显示**：
  - 封面状态：不支持、内置封面、等待下载封面、下载封面中、下载完成
  - 转码状态：等待转码、转码中、转码完成、合并完成、错误

- ✅ **转换控制**：
  - 开始转码（支持并发处理）
  - 停止转码（可在转换过程中停止）
  - 转换完成后显示成功/失败统计弹窗

- ✅ **日志功能**：
  - 底部日志窗口显示总日志
  - 选中文件时显示该文件的处理日志

- ✅ **设置功能**：
  - 是否自动下载封面
  - 最大下载并发数
  - 最大转码线程数

## 技术栈

- **后端**：Go 1.18+
- **GUI 框架**：Wails v2.12.0
- **前端**：HTML + CSS + JavaScript (Vite 构建)
- **核心转换**：自研 NCM 解密算法

## 前置要求

### 开发环境

- **Go 1.18+**
- **Node.js 16+** (用于开发模式和构建前端)
- **Wails CLI v2**

### 运行时依赖

- **WebView2** (Windows 11 已预装，Windows 10 可能需要安装)
- **ffmpeg** (可选，用于将封面嵌入到音频文件中)

## 安装

### 1. 安装 Wails CLI

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

### 2. 安装前端依赖 (开发模式需要)

```bash
cd frontend
npm install
cd ..
```

## 构建和运行

### 开发模式（带热重载）

```bash
wails dev
```

这会启动：
- 后端开发服务器
- 前端 Vite 开发服务器
- 应用窗口

### 生产构建

#### 方法一：使用预编译的前端文件

```bash
wails build -s -o ncm-converter.exe
```

#### 方法二：完整构建（会自动构建前端）

```bash
wails build -o ncm-converter.exe
```

### 运行编译后的程序

```bash
.\build\bin\ncm-converter.exe
```

## 使用说明

### 1. 添加文件

点击工具栏的按钮：

- **添加目录**：选择一个目录，程序会自动搜索其中的所有 .ncm 文件
- **添加文件**：选择一个或多个 .ncm 文件
- **程序目录**：添加程序可执行文件所在的目录

或者直接将文件或目录拖放到窗口中。

### 2. 查看文件信息

文件列表显示以下信息：

| 列名 | 说明 |
|------|------|
| ID | 文件序号 |
| 路径 | 文件完整路径 |
| 曲名 | 歌曲名称 |
| 格式 | 输出音频格式 |
| 大小 | 文件大小 |
| 封面状态 | 不支持/内置封面/等待下载/下载中/下载完成 |
| 转码状态 | 等待转码/转码中/转码完成/错误 |

### 3. 右键菜单

右键点击文件列表中的项：

- **查看日志**：显示该文件的处理日志
- **打开文件位置**：在文件资源管理器中打开文件所在目录

### 4. 开始转码

1. 确认文件添加完成后，点击 **开始转码** 按钮。

转换过程中：
- 状态栏显示 "处理中..."
- 转码状态会实时更新
- 底部日志窗口显示详细的处理过程

### 5. 停止转码

点击 **停止** 按钮可以在转换过程中停止任务。

### 6. 查看结果

所有文件处理完成或手动停止后，会弹出结果统计窗口，显示：
- 成功数量
- 失败数量

### 7. 设置

点击 **设置** 按钮可以配置：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 自动下载封面 | 是否从网络下载封面图片 | 是 |
| 最大下载并发数 | 同时下载封面的最大数量 | 3 |
| 最大转码线程数 | 同时转码的最大数量 | 10 |

## 转换流程

1. **解密**：读取 NCM 文件格式，提取加密的音频数据
2. **提取元数据**：获取歌曲信息、封面图片
3. **解密音频**：使用 AES 算法解密音频数据
4. **保存音频**：保存为标准格式（mp3、flac 等）
5. **处理封面**：
   - 如果 NCM 文件内置封面，直接使用
   - 如果没有但有封面 URL，从网络下载
   - 支持嵌入封面到音频文件（需要 ffmpeg）

## 注意事项

### 关于封面嵌入

要将封面图片嵌入到音频文件中，需要安装 **ffmpeg** 并添加到系统 PATH 中。

如果没有 ffmpeg：
- 封面图片会保存为单独的 `.cover.jpg 文件
- 音频文件仍然可以正常播放

### WebView2

Windows 10 用户如果没有 WebView2 运行时，Wails 会自动提示下载。

## 从 Fyne 迁移

本项目之前使用 Fyne 框架，现已迁移到 Wails。

主要改进：
- 使用系统原生文件对话框，更稳定
- 完整的 CSS 样式定制能力
- 自动处理 UI 线程，避免手动管理
- 更小的可执行文件体积

## 常见问题

### Q: 转换后的文件在哪里？

A: 转换后的文件保存在与原 NCM 文件相同的目录下，文件名为原文件名，但扩展名改为实际的音频格式（如 .mp3、.flac 等）。

### Q: 为什么有些文件转换失败？

A: 可能的原因：
- 文件已损坏
- 文件不是有效的 NCM 格式
- 没有写入权限

### Q: 如何查看转换日志？

A: 底部日志窗口显示总日志，右键点击文件选择"查看日志"可以查看单个文件的处理日志。

### Q: 如何更新前端代码？

修改 `frontend/src/` 下的文件，然后：

```bash
cd frontend
npm run build
```

或者使用 `wails dev` 进行开发，它支持热重载。
